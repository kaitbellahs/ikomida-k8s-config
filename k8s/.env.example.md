# Environment variables

Each `environment-secret.env` lists the variables a deployment expects.
Values are intentionally not distributed. Supply your own:

| Variable | What it is |
|---|---|
| `IKOMIDA_PRIVATEKEY` / `IKOMIDA_PUBLICKEY` | RSA pair for JWT signing and verification. Generate with `operations-job`. |
| `DBHOST` `DBPORT` `DBUSER` `DBPASS` `DBNAME` | MySQL connection |
| `MQVHOST` `MQUSER` `MQPASS` `APPS_MQUSER` `APPS_MQPASS` | RabbitMQ credentials |
| `mailjetApikey` / `mailjetSecretkey` | Mailjet, for transactional email |
| `otimaTelUser` / `otimaTelPass` | OtimaTel, for SMS |
| `ASAAS_TOKEN` / `ASAAS_AUTHENTICITY_TOKEN` | Asaas payment gateway |
| `PAGSEGURO_EMAIL` / `PAGSEGURO_TOKEN` / `PAGSEGURO_APP` | PagSeguro payment gateway |
| `APPLE_APNS` / `APPLE_APNS_KEY` / `APP_STORE_CONNECT` / `APP_STORE_CONNECT_KEY` | Apple push and App Store Connect |
| `googleAdmin` | Google Cloud service account JSON |
| `RECAPTCHA_SECRET` | reCAPTCHA verification, used by the gateway |
| `CALC_DISTANCE_API_KEY` | Distance/geocoding provider |
| `PROJID` `NODE_ENV` | GCP project and runtime environment |
